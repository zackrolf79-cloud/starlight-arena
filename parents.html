For parents

Starlight Arena is a home practice game. It is not a school product and it does not replace any GVA assignment, quiz or test.

How it lines up with GVA's AI expectations

The game follows the usual expectation for students: AI can help with practice and learning, but schoolwork that is handed in or graded must be the student's own. In the game, that means:

  • ✅ Original questions only. Every question is new AI-made practice written about the same concepts as the week's lessons. Real GVA quiz, test or activity-sheet questions and answers are never copied in.
  • ✅ Hints first. Each question offers a hint and a step-by-step coach walk-through. The answer can only be revealed after the hint, so the game teaches the thinking, not just the answer.
  • ✅ Always labelled. "AI-made practice, not for graded work" stays on screen on every page and in the game.
  • ✅ No help on graded work. The game never sees or touches real assignments. Please don't use it during a live quiz or test.

Each school's AI rules can change, so check the current GVA student handbook or ask your teacher if you're unsure. If the school's guidance differs from this page, follow the school.

Privacy

  • 🔒 No personal info. The game uses a first name only. There are no accounts, logins, emails, ads, analytics, cookies or trackers.
  • 💾 Saved locally. Progress, scores, the chosen leotard, sound and theme settings are kept in this browser's local storage on this device. Nothing is sent to a server, and progress doesn't sync between devices.
  • 🖼️ Photos never leave the device. If you use "Upload my gymnast", the picture is shrunk inside the browser and stored locally. It is never uploaded. Please use a drawing or cartoon rather than a real photo of your child.
  • 🌐 Hosting. The site is a set of static files on GitHub Pages. Like any web host, GitHub may keep standard server logs (such as IP addresses) for security; see GitHub's privacy statement. The game loads nothing from other sites.

How a week works

Each week's lessons become a new set of 32 questions: 8 each for Math, ELA, Science and Social Studies. Past weeks stay in the lessons archive so they can be reviewed. A new week starts with fresh progress.
